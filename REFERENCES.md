# Design references

- Matt Pocock, `mattpocock/skills` (GitHub): https://github.com/mattpocock/skills/tree/main — used as a design reference for small, composable task-specific skills and writing workflows.
- Agent Skills specification: https://agentskills.io/specification — reference for the directory-per-skill architecture and `SKILL.md` YAML frontmatter.
- OpenAI documentation, Skills: https://developers.openai.com/api/docs/guides/tools-skills — reference for OpenAI's support for the open Agent Skills format in supported agent environments.

Accessed/checked for this package on 13 October 2026. Platform-specific import locations and capabilities can change; check the target runtime's current documentation before installation.
