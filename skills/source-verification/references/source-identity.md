# Source identity checklist

Read the item that matches the source type. Record only what you actually checked.

## Judgments and decisions

Court or tribunal, chamber or formation, case name, neutral or report citation, docket or application number, date, document type (judgment, decision, order, advisory opinion, views), stage (admissibility, merits, interpretation, reparations, costs, appeal), relevant paragraphs, procedural posture, separate or dissenting opinions, and later treatment. For international bodies, prefer the public, non-confidential version and note if only a redacted version exists.

## Legislation and administrative material

Exact title, provision, version in force at the relevant date, commencement, amendments, repeal, jurisdiction, and whether the text is official or a reproduction. Distinguish enacted law from guidance, policy, circulars, and individual decisions.

## Treaties and international instruments

Authoritative text and languages, parties, signature and ratification status for the state in question, reservations and declarations, entry into force, and the instrument's own numbering (for example, Rome Statute art 28(a) and 28(b), not 28(1) and 28(2)).

## Scholarship

Author, exact title, publication, year, volume, issue, first and last page, and DOI or stable URL.

Metadata reliability:

1. If a DOI exists, resolve it through Crossref (`https://api.crossref.org/works/<DOI>`) for volume, issue, and pages.
2. Repository records (SSRN, HAL, institutional repositories, OpenAlex) are reliable for title, author, and year but often lack pagination.
3. Never infer a page number from a DOI string or a URL.
4. If no source returns a field, leave it empty and mark it.

## Empirical and archival sources

Method, sample, period, limitations, provenance, collection or file reference, and whether the item was seen in original, facsimile, or transcription.

## Fallback ladder when an official site blocks access

Official site → official repository or mirror (for example legal-tools.org for international criminal law) → a search-result snippet from the official domain (Existence level only) → official press release (Existence level only) → authoritative secondary database → ask the user. Stop at the first level that meets what the claim needs, and record the level reached.
